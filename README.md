PM DevCoords

A FiveM developer coordinate capture utility for PowerMoves RP.

PM DevCoords allows developers to point at locations in the game world, capture "vector3" and "vector4" coordinates, organize them into custom-named groups and collections, and export the results as Lua-formatted files.

Features

- Aim-based coordinate capture
- "vector3" and "vector4" output
- ox_lib interface
- Custom-named groups, collections, and points
- Multiple point capture with undo functionality
- Persistent coordinate storage and Lua exports
- Access through existing server ACE administrator permissions

Requirements

- FiveM
- ox_lib
